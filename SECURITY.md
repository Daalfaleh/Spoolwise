# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed credential. Contact the repository owner privately through their GitHub profile and include the affected component, reproduction steps, likely impact, and any suggested mitigation.

Please avoid accessing, modifying, or retaining data that does not belong to you. The maintainer will acknowledge a complete report as soon as practical and coordinate remediation and disclosure.

## Supported version

Security fixes are applied to the latest commit on `main`. Older snapshots are not maintained separately.
